# 🕹️ Controles de Juego

| Control           | Acción                                        |
| ----------------- | --------------------------------------------- |
| ← / →             | Mover pieza lateralmente                      |
| ↓                 | Caída rápida                                  |
| ↑                 | Mantener (“hold”) la pieza actual             |
| Z                 | Rotación antihoraria                          |
| X                 | Rotación horaria                              |
| Space             | Caída instantánea (“hard drop”)               |
| Shift + Clic Izq. | Tomar bloque (costo: incrementa linealmente)  |

!!! warning "Importante"
    El costo de tomar bloques aumenta linealmente según el nivel; ¡úsalo con criterio!

=== "Windows - Release"
    ```bash
    TetrisChafa.exe
    ```
=== "Linux/macOS (Pendiente)"
    ```bash
    ./TetrisChafa
    ```
